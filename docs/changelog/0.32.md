# 0.32 migration

## IC Platform 0.5

Host selects published `ic-platform = "0.5"` with defaults disabled. The lock
selects 0.5.0, archive checksum
`071793369ed93c3a42dae9a19eedfa76856ca2d0b31f03de7167ae7905bdc4f4`, from Platform
source `b840423928f0ca7f14d7fc860508730c87356640`.

Registry's `canister_range_start_from_key` returns Platform's owned `Principal`,
and `validate_routing_table_shard_bounds` accepts it. Platform 0.4 and 0.5 are
separate Cargo package identities: downstream code passing those values must
align its direct Platform selection to 0.5 alongside Host 0.32. This makes the
combined pending release a minor hard cut, despite unchanged Principal bytes.

```toml
[dependencies]
ic-host-tools = { version = "0.32", default-features = false, features = ["registry"] }
ic-platform = { version = "0.5", default-features = false }
```

External SDK/Candid DTOs still use `principal::ExternalPrincipal`; explicit
conversions preserve bytes. Registry Protobuf tags, shard admission, certificate
CBOR and bounded reply decoding are unchanged. No wire or storage migration is
required. Query's Registry integration is an actual consumer; update its Host
requirement and lockfile after a containing Host release is published.

Host does not use Platform's changed runtime calls, lifecycle macros or service
generation macros. It does not enable `runtime`, `cdk` or `candid-service`.
The existing optional `candid` feature continues to select codec and parser;
default, certificate-only and interface-only graphs retain their exclusions.
The Rust 1.88 floor remains unchanged.

## Shared Tooling

Shared Tooling 0.25.8 is adopted at `0a2d2ee3b5e0ae77755c2915ac28836d4d5ba359`.
`make clippy-workspace` retains the existing all-target/all-feature workspace
scope and warning policy. CI runs it after prerequisite checks and before
formatting fixtures, product tests and documentation builds. Release validation
uses that same CI path. Both publication modes run it after source admission and
before packaging or registry dispatch; a failed lint stops later stages under
parallel Make too. The focused package-only `make clippy PACKAGE=...` is unchanged.

Numbered `## [X.Y.Z] - Unreleased` and plain numbered pending headings are both
accepted. Release preparation replaces the marker with its saved UTC date;
historical release bytes and conflicting-date refusal are preserved.

The existing 125-file selection also retains the prior release-diagnostic and
failure-evidence guidance updates. Tool pins and build-helper identity are
unchanged; no tool reinstallation is required for this tooling adoption. Host
retains its own release adapter rather than selecting Shared's standalone
Cargo-metadata checker. Package versions remain 0.31.2 while notes are prepared.
