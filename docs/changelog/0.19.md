# 0.19 — Complete RSS observations and private-parent admission

## [0.19.1]

Extend the shared duration module with Query's `parse_duration_seconds` and
`display_duration_seconds`, plus `DurationParseError` retaining rejected input.
Parsing admits positive unsigned seconds or `s`/`m`/`h`/`d` suffixes without
trimming, and rejects zero, malformed values and multiplication overflow.
The separate rounded formatter selects days/hours/minutes/seconds and uses
integer half-up hundredths. It preserves Query output through the full u64 range;
it does not change Canic's compact truncating policy. No dependencies are added.
Query adoption requires a published release and a consumer hard cut, with no
compatibility reexport. Deadlines, cache freshness and raw persisted units remain
consumer-owned. Pending note selection follows this stacked branch's existing
entry and must be reconciled to the selected release before integration.

`ic_host_text::duration::compact_duration` formats whole seconds using at most
two adjacent units, seconds through weeks. It truncates smaller units without
rounding and handles the full u64 range with integer arithmetic. The implementation
and original duration examples come from Canic; boundary tests cover each unit
transition and the maximum input. No dependency or package version changes.


## [0.19.0]

### Breaking

#### RSS observations

RSS sampling now takes `sampling::snapshot(record_bytes, command_limits)`, where
`command_limits` is the existing `OutputLimits` type. Callers choose macOS
stdout/stderr bounds and an optional deadline; `timeout: None` introduces no
elapsed-time limit. Linux still uses its per-record byte allowance and ignores
command limits. macOS still reports RSS in 1024-byte units.

The native table command uses the existing direct-child capture engine instead
of an independent unbounded command-output path. Nonzero exits and capture
failures retain bounded output and original typed/cleanup causes through
`SamplingError::Command`, replacing `CommandFailed`. Stderr is captured rather
than printed by the library. Consumers own diagnostic presentation.

Successful captures must also be complete before parsing: a truncated prefix
containing valid rows is refused rather than returned as a complete snapshot.
Process selection, cadence, aggregate parsed-table memory and workload lifecycle
remain consumer-owned. Capture deadlines retain the engine's synchronous syscall
and cleanup limitations
([#130 — Native RSS command capture](https://github.com/dragginzgame/ic-host-tooling/issues/130)).

Linux stat records now use the existing bounded artifact reader. An oversized
record refuses before parsing, including when the cutoff falls inside a numeric
RSS field. Exact-bound records remain valid. Byte/allocation refusals preserve
their typed artifact cause inside `SamplingError::Io`; invalid UTF-8 remains an
I/O `InvalidData` error. Native disappearance and permission failures keep their
existing skip rules. Consumers must choose an allowance for a complete record,
rather than relying on an accepted prefix.

#### Private parent directories

`durable::prepare_private_parents` checks every existing path component before
creating missing directories. It refuses ancestor symlinks, including when the
selected descendant already exists, and rejects `..` before creation. Callers
intentionally selecting an alias must provide its canonical physical path.
The helper still creates only missing owner-only directories and synchronizes
each new directory and parent link. Existing permissions and refusal-path bytes
remain intact. Callers still own namespace exclusion and root confinement;
these pathname checks do not provide descriptor-relative confinement
([PR #90 — Reject symlink ancestors](https://github.com/dragginzgame/ic-host-tooling/pull/90)).

### Changed

Filesystem tests share one private native FIFO creator. Existing caller-selected
permissions/default umask behavior, real special-file refusal and no-writer
assertions remain intact. This adds no public fixture API or production tool
dependency.
