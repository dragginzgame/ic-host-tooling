# 0.22 — Root-relative no-follow reads

## [0.22.0]

### Added

Unix root-relative no-follow opening admits regular files and directories
through retained parent descriptors. Traversal, symlinks and unsupported entries
refuse; unsupported entries report their observed file kind. Callers own root
custody, content validation, byte budgets and concurrent writer exclusion.
Directory renames preserve the selected descriptor but do not prove current
pathname containment. This covers the read subset of
[#80 — Capability-rooted filesystem confinement](https://github.com/dragginzgame/ic-host-tooling/issues/80); create/remove/scan work remains separate.

`durable::copy_verified` composes regular descriptor admission, bounded copy
hashing and the existing publication engine. Digest mismatch, source refusal
and byte-limit failure preserve prior output. The following-symlink policy,
caller byte allowance and typed before/after-publication errors remain explicit.
Callers keep destination reuse, independent retained rehash and release receipts
([#102](https://github.com/dragginzgame/ic-host-tooling/issues/102)).
