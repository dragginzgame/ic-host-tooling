# 0.22 — Existing lock and directory commit primitives

## [0.22.0]

### Added

Host FS admits an existing regular lock sidecar without creating a missing
entry and offers one nonblocking exclusive descriptor lock. The directory
commit primitive accepts one caller-verified, synchronized tree, publishes it
by no-replace sibling rename, and synchronizes its parent. Recovery verifies
an already-canonical tree; errors after rename retain the visible name for
explicit reconciliation. Consumers retain checksums, journals, namespace
custody and retry authority. Backup adoption requires a published Host version
and its own qualification.
