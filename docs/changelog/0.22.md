# 0.22 — Exact streams and bounded host fixtures

## [0.22.0]

### Added

Unix root-relative no-follow opening admits regular files and directories
through retained parent descriptors. Traversal, symlinks and unsupported entries
refuse; unsupported entries report their observed file kind. Callers own root
custody, content validation, byte budgets and concurrent writer exclusion.
Directory renames preserve the selected descriptor but do not prove current
pathname containment. This covers the read subset of
[#80 — Capability-rooted filesystem confinement](https://github.com/dragginzgame/ic-host-tooling/issues/80); create/remove/scan work remains separate.

Process's opt-in `test-support` feature exposes `testing::http` for bounded raw
requests on caller-owned sockets. Whole-request and phased request-line/completion
readers share framing admission and one deadline. They reject ambiguous lengths,
transfer encoding, oversized or truncated requests, and unexpected trailing
bytes. Whole capture retains partial bytes and typed framing or socket failures.
Callers choose whether `Content-Length` is required and supply byte limits;
responses, authentication, evidence publication and application classification
remain local. The HTTP fixtures are portable native Rust, while executable
scripts and crash barriers remain Unix-only. This completes
[#123 — Own bounded synthetic HTTP request fixtures](https://github.com/dragginzgame/ic-host-tooling/issues/123).

### Controlled command execution

Group capture accepts caller cancellation, explicit cleanup and an optional shared
absolute deadline through the existing bounded process engine. Invalid bounds,
initial cancellation and expired deadlines refuse before command effects; the
earlier relative/absolute deadline applies without a finite default.
`run_group_command` preserves caller-selected IO, including inherited build output
and file-backed streams, while the capture entry point selects piped output.
Consumers retain command/environment selection, budgets, success requirements and
recovery. Original spawn/capture failures and separate cleanup evidence survive
([#95 — Cancellable group capture](https://github.com/dragginzgame/ic-host-tooling/issues/95)).
