# 0.22 release notes

## 0.22.0

- Add `ic_host_text::progress::ProgressLine` for pure update, finish and clear
  frame construction. It escapes unsafe text before Unicode scalar-width
  accounting, including wide and combining characters. Joined emoji follow the
  existing conservative table/clipping policy.
- Callers retain terminal admission, byte/column limits, prevention of wrapping,
  output destinations, writes, flushes, error policy and cleanup timing. Returned
  frames contain explicit carriage returns and an optional final newline; write
  them verbatim. Dropping the value performs no IO.
