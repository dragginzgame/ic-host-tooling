# 0.22 — Exact streams and durable host primitives

## [0.22.0]

### Added

Unix root-relative no-follow opening admits regular files and directories
through retained parent descriptors. Traversal, symlinks and unsupported entries
refuse; unsupported entries report their observed file kind. Callers own root
custody, content validation, byte budgets and concurrent writer exclusion.
Directory renames preserve the selected descriptor but do not prove current
pathname containment. This covers the read subset of
[#80 — Capability-rooted filesystem confinement](https://github.com/dragginzgame/ic-host-tooling/issues/80); create/remove/scan work remains separate.

Host FS admits an existing regular lock sidecar without creating a missing
entry and offers one nonblocking exclusive descriptor lock. The directory
commit primitive accepts one caller-verified, synchronized tree, publishes it
by no-replace sibling rename, and synchronizes its parent. Recovery verifies
an already-canonical tree; errors after rename retain the visible name for
explicit reconciliation. Consumers retain checksums, journals, namespace
custody and retry authority. Backup adoption requires a published Host version
and its own qualification.
