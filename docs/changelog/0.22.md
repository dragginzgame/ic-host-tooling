# 0.22 — Bounded synthetic HTTP request capture

## [0.22.0]

### Added

Process's opt-in `test-support` feature exposes `testing::http` for bounded raw
requests on caller-owned sockets. Whole-request and phased request-line/completion
readers share framing admission and one deadline. They reject ambiguous lengths,
transfer encoding, oversized or truncated requests, and unexpected trailing
bytes. Whole capture retains partial bytes and typed framing or socket failures.
Callers choose whether `Content-Length` is required and supply byte limits;
responses, authentication, evidence publication and application classification
remain local. The HTTP fixtures are portable native Rust, while executable
scripts and crash barriers remain Unix-only. This completes
[#123 — Own bounded synthetic HTTP request fixtures](https://github.com/dragginzgame/ic-host-tooling/issues/123).
