# IC Tooling 0.65

## [0.65.0] - Unreleased

### Native Serde Wire calls

The workspace adopts published IC Wire 0.6.4. Wire removed its finite `Method`
trait, typed retained frames and finite serializer. Testkit's optional native
helpers now compose Wire's `native` request/response functions directly. They
accept a `WireCallSpec` containing the exact exported method, stable method ID
and independent request/response limits. No replacement method trait or codec
is supplied by Testkit.

Replace `query_wire::<Method>(pic, canister, caller, request)` with
`query_wire::<Request, Response>(pic, canister, caller, spec, request)`; update
calls use the same signature. Requests implement `serde::Serialize` and can
borrow their fields. Responses implement both `Serialize` and
`serde::de::DeserializeOwned`, because Wire verifies canonical bytes and Testkit
releases the reply buffer. Select integer types explicitly where inference would
otherwise choose a different Serde representation.

Use the same native Serde contracts, stable IDs and explicit budgets at both
ends. Finite derive field IDs no longer determine serialization order; ordinary
Serde declaration order and custom serializers govern bytes. Qualify existing
protocols and regenerate affected metadata/clients before adopting. Retained
finite frames are not migrated or replayed automatically.

Native admission charges Serde traversal rather than static finite schemas.
Requalify bytes, allocation, nodes and depth allowances; frame byte limits include
the 11-byte header. Budget refusals return Wire's `Limit`; the removed
`SchemaLimit` variant is no longer emitted. Response size, identity/direction,
canonical payloads and work admission remain Wire-owned. Testkit still executes
one explicit query/update, preserves structured rejections and typed errors,
resumes unrelated panics and never retries an uncertain update.

The private installed probe and its native drivers migrate together to ordinary
Serde serialization with explicit method IDs. Its 64-byte pre-copy frame cap
remains, with separately qualified native traversal allowances. Wire remains
opt-in and native-only for the published Testkit package; its deployed library
does not acquire Wire, metadata, JSON, Host or Candid dependencies.
