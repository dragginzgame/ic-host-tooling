## [0.62.0] - 2026-10-20

The first coordinated release brings the existing Host crates, ic-build,
ic-testkit and ic-testkit-native into one repository and release sequence.
The repository is now https://github.com/dragginzgame/ic-tooling.
Package names and public implementation contracts remain intact; Rust 1.91
is the common minimum. The inspection application also shares this version.

Consumers exchanging Host values must update their direct Host, Build and
Testkit requirements together to 0.62 after publication, then refresh their
lockfile and qualify their selected features. The pre-1.0 package identities
change even where implementations are unchanged. Platform remains a separately
owned 0.5 dependency. Do not use an unrelated broad dependency update as a
substitute for this coordinated selection.

Default features remain empty where previously empty. Build does not depend on
Testkit. The Testkit library does not depend on Build; its private development
driver does. Native-only Host and PocketIC dependencies remain excluded from
Testkit's declared deployed Wasm profiles. Private development/probe packages
are never published. No wire format, cache namespace or artifact lifetime
change is part of the consolidation.

Shared Tooling still owns common scripts. One snapshot, dependency catalog,
lockfile and publication adapter serve the workspace. Publication selects the
nine public packages explicitly; Cargo owns their dependency order. Existing
source, license and retained-attempt checks continue to apply. Publication is
not atomic: retain failed attempts and reconcile partial uploads before retry.

Old repository retirement follows combined-workspace qualification, release
and consumer migration. Preserve unmerged PRs, the saved Build stash, branches
and retained artifacts. See the [source inventory](../design/tooling-consolidation.md).
